## ระบบทำงานอย่างไร

สองโครงการต้นทางยังเป็นผู้ผลิตข้อมูล MAIAC/CAMS และ FIRMS/Emission แยกกัน โครงการนี้รับเฉพาะผลที่เผยแพร่แล้วจากแต่ละ Git commit มาตรวจสอบและจัดเก็บเป็น snapshot จากนั้นจึงเผยแพร่หน้าเว็บกลาง ไม่เรียก API NASA/ADS/FIRMS ซ้ำ ไม่คัดลอก API key หรือไฟล์โมเดล และไม่เปลี่ยนวิธีคำนวณต้นทาง

ไฟล์เว็บไซต์อยู่ใน `web/` ข้อมูลอากาศใน `web/data/air/` และข้อมูลไฟใน `web/data/fire/` รายละเอียด commit การรับข้อมูล เวลาเดิม และสถานะอยู่ใน `manifest.json` รหัสกริดสองระบบต่างกันแต่กริดจริงตรงกัน 1,052 ช่อง ตาราง `grid_crosswalk.json` เชื่อมผ่านตำแหน่ง UTM EPSG:32647 และตรวจพิกัดรูปทรงหลังตัดขอบเขต

เมนูภาพรวมสถานการณ์ การประมาณค่าฝุ่น จุดความร้อนและการปล่อยฝุ่น และเกี่ยวกับข้อมูล ใช้วันที่ร่วมกัน แผนที่เปิด–ปิดชั้นฝุ่น กริดไฟ จุดความร้อน เส้นกริด และเชื้อเพลิงได้ คลิกกริดเพื่อดูข้อมูลสองระบบ พร้อมดาวน์โหลด CSV แยกหน่วยและเวลา

## ค่าเริ่มต้นและการเลือกข้อมูล

- หน้าแรกเปิดวันไทยปัจจุบัน ใช้ MAIAC ก่อนถ้ามีค่าจริง มิฉะนั้นใช้ CAMS
- เมนูมีเฉพาะ MAIAC/CAMS สลับแหล่งเองแล้วคงวันที่เดิม เมื่อเลือกวันใหม่ระบบเลือกแหล่งตามข้อมูลของวันนั้นอีกครั้ง
- CAMS ของวันนี้/อนาคตเลือกชั่วโมงที่ใกล้ปัจจุบันที่สุดภายในวันที่เลือก วันที่เก่าใช้ค่าเฉลี่ยรายวัน ปุ่มใกล้เวลาปัจจุบันจะกลับสู่ชั่วโมงพยากรณ์ที่ใกล้ตอนนี้ที่สุด
- MAIAC แสดง IDW กำลัง2 ใกล้ที่สุดไม่เกิน12จุด ระยะทาง UTM ต้องมี3จุดไม่เรียงเส้นตรง ถ้าทำไม่ได้จะแสดงเฉพาะกริดที่มีข้อมูลพร้อมระบุว่าค่าเฉลี่ยครอบคลุมบางส่วน
- PM₁ = 0.80 × PM₂.₅ − 0.71 และ PM₀.₁ = 0.14 × PM₂.₅ − 0.40 ที่มา (CALLAB) ตามข้อมูลผู้จัดทำ ค่าติดลบเป็น NoData ไม่แทนศูนย์
- สี PM₂.₅ แบ่งที่15/25/37.5/75, PM₁ ที่12/20/30/60, PM₀.₁ ที่2.25/3.75/5.63/11.25 µg/m³ รหัสสี PM₁/PM₀.₁ เป็นเบื้องต้น ไม่ใช้ตัดสินผลกระทบสุขภาพ 80%/15% ใช้กำหนดช่วงสี ไม่เปลี่ยนสัมประสิทธิ์0.14
- FIRMS เลือกดาวเทียม กลุ่มกริด/กริดรายช่อง และเปิด–ปิดสถานการณ์ดินพรุ0–10ซม. โดยใช้ผลเดิมของต้นทาง

## ข้อจำกัดในการอ่านร่วมกัน

ความเข้มข้นฝุ่น µg/m³ ต่างจากปริมาณการปล่อย kg ต่อวันที่เลือก ห้ามบวกหรือแปลงเป็นกันโดยตรง MAIAC ใช้วันผลิตภัณฑ์ UTC ข้อมูลไฟและ CAMSรายวันใช้วันไทย การเปรียบเทียบป้ายวันที่เดียวกันเป็นการสำรวจ ไม่ใช่การยืนยันว่ามีช่วง24ชั่วโมงเดียวกันหรือยืนยันเหตุและผล

CAMS มีความละเอียดต้นทาง0.4° แม้แสดงตัดตามขอบเขตศึกษา การประมาณ PM₂.₅ จาก CAMS AOD550 ยังใช้ Extra Trees เดิมที่ฝึกกับ AOD470 ผลยังไม่ได้สอบเทียบสถานี ไม่ใช่ PM₂.₅ พยากรณ์โดยตรงจาก CAMS

Emission เป็นสถานการณ์สมมติเผาเต็มส่วนกริดที่อยู่ในขอบเขต จุดความร้อนเป็นศูนย์กลางตรวจพบ ไม่ใช่รูปทรงพื้นที่เผายืนยัน ค่าใช้พื้นที่×ρ×η×EF ชั้นเชื้อเพลิงที่ทับซ้อนคงทับซ้อน รายวันอิสระไม่หักเชื้อเพลิงจากวันก่อน และไม่ใช้ผลรวมหลายวันเป็นพื้นที่ไฟที่ไม่ซ้ำ

สถานะรับsnapshotสำเร็จไม่ได้หมายถึงทุกดาวเทียมมีข้อมูลครบ ต้องดู `observation_state` และสถานะแยกแหล่งด้วย ค่าศูนย์ในชุดบางส่วนหมายถึงไม่พบในข้อมูลที่ได้รับ วันที่วันนี้ยังอาจไม่ครบวัน

Workflow `.github/workflows/platform.yml` รับข้อมูลจากสองคลังทุกชั่วโมงที่นาที17และ47 (ทุกประมาณ30นาที; GitHubอาจเริ่มช้าตามคิว) และเมื่อpushโค้ดหรือสั่งรันเอง ระบบอัปเดตได้แม้ปิดคอม ข้อมูลใหม่ขึ้นกับรอบและความพร้อมของต้นทาง ไม่มีการสร้างงานAutomationในแชต

## พัฒนาและทดสอบ

Python3.12, Node22 และ Shapely2.1.2 สำหรับรวมกริดเชิงเรขาคณิต:

```powershell
cd 'D:\LAB website\kuan-kreng-monitoring-platform'
python -m pip install shapely==2.1.2
python scripts/sync_data.py

python -m unittest discover -s tests -p 'test_*.py' -v
node --test tests/model.test.cjs tests/charts.test.cjs
node --check web/app.js
```

เปิด `http://127.0.0.1:8770/` วิธีรับข้อมูลแบบofflineจากสำเนาท้องถิ่นและรายละเอียด schema ดู `docs/DATA_CONTRACT.md` ใช้สำหรับพัฒนาเท่านั้น การเผยแพร่จริงรับจาก upstream GitHubที่ pin commit

ใบอนุญาต Leaflet อยู่ใน `web/vendor/LEAFLET-LICENSE.txt` ใช้ Proj4js2.23.0 ซึ่งตรวจSRIเทียบรุ่นเดิมก่อนจัดเก็บ OpenStreetMap/Esri attribution แสดงบนแผนที่ ข้อมูล CAMS อ้างอิง Copernicus/ECMWF CC-BY ส่วน NASA MAIAC/FIRMS และสมการ/พารามิเตอร์ใช้ที่มาตามโครงการต้นทาง


## ปฏิทิน ตัวเลือกแผนที่ และกราฟ

ชุดเลือกวันอยู่ใต้เมนูด้านซ้าย มีปฏิทินพร้อมจุดบอกข้อมูล ปุ่มก่อนหน้า/ถัดไป แถบเลื่อน และวันล่าสุดที่มีข้อมูล วันที่ยังเลือกดูได้แม้ไม่มีข้อมูล แต่เครื่องหมายแสดงตามหน้าและแหล่งข้อมูลที่กำลังเลือก: สีเขียวมีค่าฝุ่น สีส้มพบจุดความร้อน วงกลมโปร่งคือมีข้อมูลไฟแต่ไม่พบจุด (ยังแยกสถานะบางส่วน) วันพยากรณ์ CAMS อิงช่วงรายวัน/รายชั่วโมงที่เลือก ไม่ใช้ค่าจากวันข้างเคียง

แผนที่สูงขึ้นและเป็นส่วนหลัก การ์ดสรุปอยู่บนสุด ตัวเลือกเหนือแผนที่และชั้นข้อมูลเดิมคงไว้ รายละเอียดสถานะเริ่มต้นพับเก็บ เมนูมีภาษาอังกฤษกำกับและหน้าที่เรียกผ่าน hash เก่าที่ไม่มีแล้วจะกลับภาพรวม

ดาวเทียมเลือกได้หลายดวง ข้อมูลเสริม `web/data/ui/` เตรียมครบ15ชุดการเลือกสำหรับแต่ละวัน โดยรวมกริดซ้ำก่อนหายอดและจัดกลุ่มจากขอบที่ติดกันจริง ไม่บวกยอดดาวเทียมตรงๆ กราฟใช้ผลรวมชุดเดียวกับแผนที่และการ์ด วิธีตรวจสอบและ cache ดู `docs/UI_DATA_CONTRACT.md` การเปลี่ยนดาวเทียมไม่เรียก NASA API ซ้ำ

ตัวเลือกเชื้อเพลิงหญ้า กระจูด เสม็ดขาว ข้าว และดินพรุ ควบคุมเฉพาะภาพซ้อนบนแผนที่ แต่ละชุดที่เลือกสร้างภาพแสดงผลแล้ว cache ไว้ จำกัด6ภาพ ภาพถูกตัดตามขอบเขตจริง ปุ่มรวมสถานการณ์ดินพรุ0–10ซม.ยังคงเป็นตัวเลือกการคำนวณแยกต่างหาก

กราฟ Drop-line ใช้จุดแสดงค่าและเส้นประแนวดิ่งถึงฐานศูนย์ กราฟฝุ่นเลือก MAIAC/CAMS ของกราฟเองได้ กราฟไฟเลือกการปล่อย PM₂.₅ (kg) หรือจำนวนจุดความร้อน (รายการ) พร้อมช่วง30/60/92วัน ค่าศูนย์มีจุดอยู่บนฐาน ส่วนวันที่ไม่มีข้อมูลไม่มีจุดและแสดงเครื่องหมายขาดข้อมูล เลือกจุดด้วยเมาส์หรือ Enter/Space เพื่อเปิดวันนั้น

## AirThai stations on the map

The map station button opens only the six requested locations, their hourly PM2.5 popups, and an optional boundary-clipped station-IDW layer. This is measured atmospheric concentration in µg/m³, separate from AOD estimates and emission kg. No extra page section is added. Public station snapshots update with the existing GitHub schedule; no API key or open local computer is needed. See [the exact station/time/IDW contract](docs/AIRTHAI.md).

Run `python scripts/sync_stations.py --data web/data` after source mirroring. Check the integration with `python -m unittest discover -s tests -p test_stations.py` and `node --test tests/stations.test.cjs`.

ส่วนเกี่ยวกับข้อมูลเปิดเป็นหน้าต่างย่อที่เลื่อนอ่านได้ พร้อมลิงก์ GitHub อยู่ภายใน การเปิดหรือปิดหน้าต่างไม่เปลี่ยนวัน แหล่งข้อมูล หรือชั้นแผนที่ที่เลือก กล่องค่าฝุ่นอยู่เหนือวันเวลาบนแผนที่ เกณฑ์สีแสดงเป็นการ์ดที่ปรับจำนวนคอลัมน์ตามพื้นที่ โดยคงช่วงตัวเลขและสีเดิม จุดสถานีเริ่มต้นซ่อนและเปิดเองได้ (ลิงก์ที่ระบุ `stations=1` ยังคงเปิดตามตัวเลือกนั้น) สถานะ FIRMS บางส่วนแสดงในรายละเอียดชุดข้อมูลแทนแถบแจ้งทั่วไป


## VIIRS NOAA

ตัวเลือก `VIIRS NOAA` รวมเฉพาะ NOAA-20/NOAA-21 Deep Blue L2 v2.1 จากต้นทางเดิม ไม่ใช้ Suomi-NPP สำหรับชุด AOD ใหม่นี้ งานต้นทาง `.github/workflows/viirs_noaa.yml` ตรวจข้อมูลทุก 3 ชั่วโมงที่นาที43 UTC โดยใช้ NASA/model secrets เดิม เว็บกลางรับ snapshot ผ่านรอบเดิมโดยไม่รับ secret เพิ่ม

ใช้ AOD550 land best estimate และ QA2/3 เฉพาะจุดศูนย์กลางในขอบเขตพรุ รวม AOD ของวันไทยเดียวกันลงกริดรายงาน UTM 6 กม. ที่ตัดขอบเขต แล้วใช้ Extra Trees เดิมตามการยืนยันของเจ้าของโครงการ ไม่แปลงเป็น AOD470 และไม่ฝึกโมเดลใหม่ ชื่อคอลัมน์เดิม `AOD 0.47` เป็นเพียงสัญญาข้อมูลของโมเดล มีเมทาดาทาระบุว่าค่าที่ป้อนจริงเป็น550nm

มาตรฐานแทน NRT ของรอบดาวเทียมเดียวกันเมื่อพร้อม ไม่เพิ่มจำนวนตัวอย่างจากการนับซ้ำ ช่องขาดเป็น NoData ไม่มีพยากรณ์ VIIRS ค่าเฉลี่ยมาจากช่วงที่ตรวจวัดได้ ไม่ใช่ค่าเฉลี่ย24ชั่วโมง กราฟและการ์ดแสดงค่าเฉลี่ยเฉพาะช่องรายงานที่มีข้อมูลพร้อมสัดส่วนพื้นที่กริด ไม่สื่อว่าเป็นความละเอียด1กม.หรือความครอบคลุมพิกเซลจริง

เลือกแหล่งข้อมูลแล้วคงวันเดิม เมื่อใช้ VIIRS การเปลี่ยนวันยังคง VIIRS ส่วนลำดับค่าเริ่มต้น MAIAC ก่อน CAMS เดิมคงไว้ ภายหลังการเปิดใช้จะเติมย้อนหลังตามไฟล์ที่มีได้สูงสุด92วัน โดยไม่สร้างค่าทดแทนในวันที่ไม่มี AODผ่านQA
